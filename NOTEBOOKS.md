# Reproducible notebook walkthroughs

These notebooks are the companion walkthroughs to *Resource-Theoretical
Unification of Mpemba Effects: Classical and Quantum*. They are designed to be read
in order: each one introduces the resource, constructs the dynamics, verifies the
relevant structural properties, and only then tests the Mpemba crossing. A
missing crossing or a convention mismatch is reported rather than replaced by
an illustrative curve.

## Running the notebooks

The notebooks use Python 3 with NumPy, SciPy, and Matplotlib. Run them from the
repository root so that they can import [`tools/notebook_utils.py`](tools/notebook_utils.py).
Every notebook has stored outputs from a clean top-to-bottom execution.

The circuit notebooks consume raw per-realization arrays in
`data/circuit_examples/`. They show individual trajectories before any ensemble
reduction and expose regeneration instructions. The Markovian U(1) file uses the
full Fig. 9 system and ensemble size. The non-Markovian U(1) walkthrough uses
all 100 pinned gate rows from
[`alessum/mpemba_circuits`](https://github.com/alessum/mpemba_circuits) at
\(N_s=8,N_e=12\) for all 1000 layers. Its smaller \(N_s=4,N_e=8\) file is used
only for an explicit channel-mode audit. The SU(2) file uses the
manuscript Hilbert-space size \(N_s=8,N_e=12\) and all 100 realizations. Its
isotropic partial-SWAP gates commute with all three collective-spin
generators, its singlet bath is SU(2)-invariant, and its asymmetry is evaluated
with the exact Clebsch--Gordan Haar twirl. The notebook documents the
figure-matching angle and time-axis conventions used to plot the resulting
raw ensemble mean.

Both non-Markovian circuit notebooks audit the same Marvian--Spekkens
Eq. (3.10) ([arXiv:1312.0680](https://arxiv.org/abs/1312.0680)): the U(1)
walkthrough ([`asymm_ex4.1.a.ipynb`](notebooks/asymm_ex4.1.a.ipynb)) uses it as
an explicit mode-transfer reconstruction identity on the reduced channel; the
SU(2) walkthrough ([`asymm_ex5.ipynb`](notebooks/asymm_ex5.ipynb)) uses it as
the contraction bound \(|c^{(1)}|\le 1\) on the rank-1 irreducible tensor of
the isotropic partial-SWAP dilation.

## Appendix companion scope

The three appendix notebooks use the same editorial structure as the main-text
walkthroughs: paper map, reproduction status, model construction, executable
checks, final figure, and a concise result statement.

- [`non-stationarity.ipynb`](notebooks/non-stationarity.ipynb) constructs
  both pure states with a fixed-seed slow-mode search rather than loading the
  opaque `FigS1_data.pkl` artifact. It is an independent reconstruction at the
  published collective-spin parameters.
- [`atherm_ETH.ipynb`](notebooks/atherm_ETH.ipynb) keeps the manuscript \(N=15\) bath,
  all quoted couplings, \(\beta=-0.46\), and the full \(2^{16}\)-dimensional
  sparse unitary evolution. Because the two exact bath eigenvectors were not
  archived, the default calculation uses diagnosed narrow-energy Lanczos
  states and exposes an optional shift-invert eigenstate path.
- [`quantum-fisher-info.ipynb`](notebooks/quantum-fisher-info.ipynb) is an exact,
  data-free reconstruction of the single-qubit Davies calculation and audits
  SLD, Wigner-Yanase, and harmonic-mean QFI on the same trajectories.

## Maintenance

Shared numerical routines live in [`tools/notebook_utils.py`](tools/notebook_utils.py), keeping
the notebooks focused on the physics. To regenerate and execute all notebooks:

```bash
python tools/build_publishable_notebooks.py
python tools/generate_circuit_data.py
python tools/execute_notebooks.py
```

Individual notebooks can be rebuilt and executed by passing their filenames,
for example:

```bash
python tools/build_publishable_notebooks.py \
  non-stationarity.ipynb atherm_ETH.ipynb quantum-fisher-info.ipynb
python tools/execute_notebooks.py \
  non-stationarity.ipynb atherm_ETH.ipynb quantum-fisher-info.ipynb
```

The exact-size U(1) reference file has its own pinned reproduction command:

```bash
python tools/generate_circuit_data.py \
  --only u1-reference \
  --paper-scale \
  --reference-checkout /path/to/mpemba_circuits
```

The execution script uses `nbformat` and `nbclient` in addition to the runtime
dependencies above. The U(1) paper-scale command uses an exact occupied-sector
engine and concurrent circuit workers; it reproduces all 100 archived circuits
for the complete 1000-layer Fig. 10 time range on a local multicore machine.
